# Spring Security Learning Project

This project is a simple full-stack application built to learn and practice Spring Security.

It includes a Spring Boot backend with JWT authentication and a React frontend for login and registration.

## What I Learned

Through this project, I learned:
- how authentication works in a Spring Boot application
- how to configure Spring Security
- how JWT tokens are created and used
- how to protect APIs using authentication
- how frontend and backend work together in a secure login flow

## Features

- User registration
- User login
- JWT-based authentication
- Protected routes and APIs
- Basic frontend pages for login, register, and dashboard

## JWT Learning Notes

I also learned about JWT token structure:
- Header: contains the token type and signing algorithm
- Payload: contains user information and claims
- Signature: ensures the token is authentic and has not been changed

I also practiced checking and understanding tokens on jwt.io.
